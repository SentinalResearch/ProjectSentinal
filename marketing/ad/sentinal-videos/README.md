# Sentinal videos (source)

- `Sentinal Film.dc.html`: 60s product walkthrough (sentinal-film.jsx)
- `Sentinal Film - Keynote cut.dc.html`: 60s keynote-style ad (sentinal-keynote.jsx)
- `animations-v3.jsx`: timeline engine · `support.js`: runtime

Open either `.dc.html` through a local server (`npx serve .`); opening the file directly from disk may block the script loads.
Format (16:9 / 1:1 / 9:16) is the `format` prop.
Scene timings live in the `OM_SCENES` JSON inside each `.dc.html`.

## MP4
Open the file in the editor and choose Share → Export → Video, once per format you need.
