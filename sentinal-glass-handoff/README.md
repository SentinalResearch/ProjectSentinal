# Sentinal glass handoff

- `PROMPT.md`: paste into your coding agent.
- `GLASS_SPEC.md`: tokens, the glass recipe, island, prompt grammar, sheets, dashboard and session layouts.
- `design/Sentinal Glass.dc.html`: the chosen design (Dashboard, Prompt open, Session).
- `design/Sentinal Nav Options.dc.html`: the explorations (1a–1c, 2a–2c) for context.
- `design/support.js`: needed to open the .dc.html files. Run `npx serve design` and open them in a browser.

To update the design later: edit values in `GLASS_SPEC.md` §1 (tokens) and §4–8 (layouts). The agent prompt points to the spec, so changes there carry through.
