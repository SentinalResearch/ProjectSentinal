# Progress reports

Files in this directory are point-in-time milestone evidence. Commands, test
counts, operating-system versions, and limitations describe the date and
commit recorded by that report; they are not rolling claims about current
HEAD.

Use `docs/AUDIT_TRACKER.md` for the current repository-wide verification
record and release blockers. New milestone reports must record the tested
commit, exact commands, host/OS information for manual runs, and any external
prerequisite that prevented a check.
